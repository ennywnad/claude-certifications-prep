How to use this guide. The single answer is rarely the hard part — the incorrect options are written to look right to someone with partial knowledge. So for each question, read why the three distractors fail. They almost always fail for the same handful of reasons, collected in the Principles and Traps tabs. Master those and you can reason to the answer even on a question you've never seen.

Decision Principles

These recurring rules decide most questions. When stuck, run the answer options past the one that fits the situation.

Traps & Exceptions

Wrong answers that look right, plus the one condition that flips a normally-correct approach into the wrong one.

Task Recall

High-level build playbooks — the steps to actually do each thing the exam covers, from setup through verification. Knowing the sequence lets you spot the missing or out-of-order step in an answer.

Visual Map

The shapes behind the questions — what a request actually contains, how the loop turns, where hooks bite, and how the decision trees branch. Skim these before a practice run to load the structure, then let the questions test it.
